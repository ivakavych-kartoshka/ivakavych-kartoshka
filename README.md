```text

   Transformer Encoder
           │
           ▼
 Custom Classification Head
           │
           ▼
 Multi-Label Predictions
           │
           ▼
   Model Evaluation
```

**Exploring**

`Multi-label Classification` · `Threshold Optimization` · `Label-aware Attention`
